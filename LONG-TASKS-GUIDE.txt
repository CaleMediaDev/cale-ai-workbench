LOCAL AI LONG TASKS

Open "Cale AI Workbench" on your desktop. Setup progress and optional model
downloads appear in My tasks. Type in the chat what you want built,
and let the app make a folder and local memory database automatically.

It will keep working through a saved plan, test its work, and use a separate
local-model review pass. You can close the window while it runs. The normal
"Local AI" shortcut still opens the interactive assistant.

CONTROLS
Pause: stops further progress; a retiring worker can take up to two minutes.
Stop: ends the task permanently but preserves its project files.
Delete: removes the task from the app but preserves its project files.
Continue: resumes from the project's files, saved plan and task history.
Add instructions: answers a blocker or adds requirements and resumes the project.
Open files: opens the actual files in Explorer.
Looks good: records your acceptance after fresh checks and review.

STATUS
Working: building, reviewing, queued for the single worker, or settling a handoff.
Checking: the supervisor is running the project's tests independently.
Needs input: a blocker, repeated failures, or changes after verification need attention.
Ready for review: build + separate AI review + independent test execution passed.
Accepted: you accepted the result; files and history remain on disk.

WHAT SURVIVES RESTARTS
Hermes stores tasks, claims, failures, comments and runs in its SQLite board.
The companion separately stores projects, requests and verification state.
The agent maintains .local-ai/PLAN.md and PROGRESS.md inside each project.
It also keeps a SQLite full-text memory index in .local-ai/memory.sqlite3.
This is created automatically; there is no separate database installation.
After a crash, a replacement worker reads those files and prior task context.
Context compression and fresh review sessions prevent one conversation growing forever.

Windows task "CaleAI_LongTasks" starts the supervisor at your sign-in, restarts
it after a crash, and has no execution-time expiry. It starts the local Hermes
gateway and Ollama when queued work needs them. Only one board worker runs at once.
Pause and blocked states persist. A verification process belongs to a Windows Job:
if the supervisor crashes, its verification descendants are retired automatically.

Your PC must be on and awake for work to run. It cannot build while shut down,
asleep, or signed out. After restarting Windows, sign in and it resumes.
Power settings were not changed. Locking the screen is fine while the PC stays awake.

DEFAULT LIMITS AND CHECKS
Each native goal card allows up to 1,000 continuation turns and a 30-day attempt.
The native dispatcher recovers crashed workers and blocks repeated failures.
The companion retries failed handoff checks twice, then asks for input on the
third failure. Each independent verification has a 20-minute timeout.
The agent must provide .local-ai/verify.ps1 with actual behavioral tests; missing
or failed verification never produces Ready for review. A separate local worker
reviews requirements, implementation and tests, followed by another independent run.
Source changes after a pass invalidate acceptance. Paused workers are allowed to
retire before a resume to avoid overlapping edits.

These are bounded continuations, not a promise that every project can be finished
without help. The local model can still misunderstand requirements or write weak
tests. Review the actual app before accepting. Passing an agent-written test suite
is evidence, not proof of complete correctness. This setup has been tested with
short real tasks and simulated failures; it has not been run for several weeks.

FILES AND TOOLS
See TOOLBOX.txt for REA, Ghidra, Chrome DevTools, code search, documents and SQL.
Existing project instructions are preserved. Use a dedicated folder per project;
the companion rejects overlapping project folders in its queue.
Queued projects use your Windows account permissions. No WordPress credentials,
personal browser cookies or Codex connections were copied to this local assistant.
OpenRouter free models can be connected, with local fallback. ChatGPT plan use
requires a separate choice and uses the shared ChatGPT/Codex allowance.

STARTUP CONTROL
Run "Disable Long Tasks Startup.ps1" to disable future automatic starts.
Run "Install Long Tasks Startup.ps1" to re-enable it.
Use Pause or Stop on a task card to halt it.
