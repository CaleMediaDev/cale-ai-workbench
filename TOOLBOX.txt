LOCAL AI TOOLBOX

Ask Local AI to use tools directly. Reasoning uses local Ollama by default;
the optional connected account can use free cloud inference with local fallback.

Already available: terminal commands, read/write/patch files, file search,
Git, Python, Node, memory, reusable skills, public web search and page reading,
Playwright browser automation, and persistent Hermes task boards.
For a task needing a workflow Cale lacks, skill_hub_search finds candidates,
skill_hub_inspect previews one, and skill_hub_install lets Hermes scan and
install it without force. Do not install a skill merely because it ranks highly.
Each project automatically gets a local SQLite FTS5 memory database in
.local-ai/memory.sqlite3. No database software, account, or setup is needed.
Use project_memory_search for ranked snippets, project_memory_get for a full
record, project_memory_save for requirements/decisions/lessons/skills/components,
and project_memory_index to refresh code files. Pass the exact project folder.
Use search_computer_files to locate files or folders by name across accessible
local drives. Its background index stores paths only, never document contents.
Files remain the source of truth; re-read them before changing code.
Use crawl_website for bounded, same-host public website research. It runs
Crawl4AI locally in a headless browser, respects robots.txt, saves Markdown
under Research/Web in the project, and indexes it in the local SQLite memory.
It does not require an account. The browser can render JavaScript-heavy pages.
Public search uses Brave with DuckDuckGo Lite fallback if the first service is
rate limited. Search links are leads; read the destination page for evidence.

NEW SPECIALIST TOOLS
Call mcp__toolbox__toolbox_search with a short purpose, then toolbox_schema
with an exact returned name. Pass its arguments to toolbox_call as arguments_json.
This exposes the full installed REA and Chrome DevTools catalogs on demand.
Always read the returned schema; never guess argument names.
Use toolbox_status to check whether each specialist backend started. If one
is unavailable, local memory, media, document, and training tools still work.

REA (official morluto/rea, rea-agents 6.8.0): static JavaScript/Electron analysis,
application structure, imports, routes, source maps, native binary inspection,
Ghidra decompilation, .NET metadata/CIL, PE imports/certificates, packaged Python,
SQLite inspection, model artifact metadata, HAR captures, web observations,
evidence comparisons and reconstruction workflows. Some catalog tools require
platforms, hardware or optional engines not installed here; read capability errors.
Ghidra 12.1.4 and Temurin JDK 21 are included for supported Windows native PE analysis.
REA's Windows Ghidra support is experimental and does not offer every Linux feature.

Chrome DevTools 1.12.0: browser console errors, network requests, screenshots,
DOM interaction, performance traces, memory debugging and device emulation.
It uses an isolated browser, not your signed-in personal browser. Telemetry and
CrUX URL lookup are disabled. Playwright remains available for repeatable tests.
Hermes Connector 0.2.6: the local companion is installed automatically. Use
"Connect my Chrome tabs" under Supercharge to approve its Chrome extension,
paste the local pairing code, and attach selected signed-in tabs to a task.
Then the agent can use bridge_status and bridge_* tools on those tabs only.

document_to_text: local PDF, Word, Excel, PowerPoint, HTML, CSV and text extraction
using Microsoft MarkItDown. No external AI, image descriptions or cloud OCR.
sqlite_read: read-only SQL on existing local databases.

LOCAL DESIGN TOOLS
scan_frontend_design: audit a local HTML/CSS/JavaScript/React file or folder for
generic design patterns, with source locations. This bundles the MIT-licensed
avoid-ai-design scanner. Findings are suggestions; render the result and judge it.
check_color_contrast: calculate WCAG AA/AAA text contrast for two hex colors.
Use Chrome DevTools or Playwright to inspect real pages and screenshots, and
make_image for locally generated design assets. These tools need no account.

LOCAL MEDIA AND TRAINING TOOLS
make_image: generate a PNG locally with LCM Dreamshaper v7.
see_image: describe a photo, screenshot or chart with local Qwen vision.
hear_audio: transcribe a local audio/video file with Faster-Whisper base.
watch_video: inspect up to eight sampled frames and optionally transcribe audio.
camera_snapshot: capture one frame only while Camera is enabled in the app.
watch_camera: inspect up to four sampled live frames over at most 30 seconds.
voice_file: create a spoken WAV file with offline Windows speech.
train_text_classifier / classify_text: train a labeled CSV text classifier and
predict with an inspectable JSON model. Evaluation uses held-out rows.
train_small_adapter / ask_small_adapter: train and use a separate 0.5B Qwen
LoRA adapter from JSONL input/output examples. The coding model is unchanged.
Camera is off by default and the app's switch expires in one hour. Video frame
sampling can miss events. The Dictate button records ten seconds from the mic
and copies the recognized text to your clipboard.

TERMINAL TOOLS (launchers put these on PATH)
rea --help             Official reverse-engineering CLI (same workflows as MCP)
ast-grep --help        Structural code search/refactoring across supported languages
ruff check .           Python linting
pytest                Python behavior tests
python                Toolbox Python: DuckDB, pandas, Pillow, pefile, Capstone,
                      openpyxl, python-pptx, MarkItDown and related document readers
node / npm            Private Node 26 runtime and normal JavaScript package tooling
git                   Existing Git installation; no GitHub account credentials added
gh                    GitHub CLI. Connect your own account in the app first.
                      Use for requested repos, pushes, releases and static Pages sites.

For repeatable browser tests use Node with require('playwright'), channel:'chrome'.
Do not use ast-grep's sg alias (it can collide with unrelated system commands).

This is a local tool suite, not a sandbox: tools run with your Windows account's
permissions. Use project-scoped tasks. GitHub Pages hosts static sites, not servers
or online stores. Codex connections and signed-in cookies are not automatically copied.
