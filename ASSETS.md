# Cale Media logo

`assets/cale-logo-original.jpg` is the logo image supplied by Cale Media. `assets/cale-logo.png` is a transparent-background version sized at runtime for the app and installer. The logo and Cale Media name are Cale Media brand assets; the repository's MIT code license does not grant trademark rights.

The app loads the PNG from its installed `assets` folder. Keep both files in the release manifest when changing the installer or packaging code.
