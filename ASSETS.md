# Cale Media logo

`assets/cale-logo-original.jpg` is the logo image supplied by Cale Media. `assets/cale-logo.png` is a transparent-background version sized at runtime for the app and installer. The logo and Cale Media name are Cale Media brand assets; the repository's MIT code license does not grant trademark rights.

The app loads the PNG from its installed `assets` folder. The ICO is generated from that PNG for the Windows window, desktop shortcut, and installer. Keep all three files in the release manifest when changing the installer or packaging code.

`assets/cale-talking.webp` is a stylized, two-frame illustrated character on a beach, generated with the owner's video as a loose character reference. It does not display the owner's real face. `assets/cale-voice-reference.wav` is a cleaned excerpt of the owner's real voice. These character and voice assets are Cale Media property and are not covered by the MIT code license. The app animates the character while speaking; it does not claim exact lip synchronization.

`assets/dgx-spark-nvidia.jpg` is an NVIDIA DGX Spark product photograph from [NVIDIA Newsroom's media assets](https://nvidianews.nvidia.com/file/nvidia-dgx-spark?action=). It is credited in the Supercharge screen, and NVIDIA retains the image rights. The repository's MIT license does not cover this photograph.
